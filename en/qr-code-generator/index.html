QR Code Generator

Type a link or text and download the QR code as an image.

How to use QR Code Generator

  1. Type the link, text or number.
  2. Choose the size and colors. Keep strong contrast between the code and the background.
  3. Press Download PNG and scan it with your phone camera before printing.

Good to know

The QR code is static: the link is written inside it and keeps working as long as the link works. There is no subscription and no expiry.

Use a dark code on a light background. Some cameras cannot read inverted codes.

Higher error correction lets the code be read even if part of it is damaged, but it makes the code larger and denser.

FAQ

Are my files uploaded?

No. Everything runs in your browser on your device.

Does the QR code expire?

No. It is static and not tied to any service.

Can I use Arabic text?

Yes. Arabic and English both work.
